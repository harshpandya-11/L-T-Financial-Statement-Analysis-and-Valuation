# Larsen & Toubro Ltd. — Financial Statement Analysis & DCF Valuation

## 📊 Project Overview

This project presents a five-year **Financial Statement Analysis and Discounted Cash Flow (DCF) Valuation** of **Larsen & Toubro Ltd. (L&T)** covering FY2022–FY2026.

The project was developed in Microsoft Excel using financial data compiled from publicly available sources, including company annual reports and Screener.in.

The objective is to analyse L&T's historical financial performance, evaluate key financial ratios, estimate intrinsic value using a DCF model, perform sensitivity analysis, and present the findings through charts and a structured financial report.

---

## 🏢 Company

**Company:** Larsen & Toubro Ltd.  
**Industry:** Engineering & Construction  
**Analysis Period:** FY2022–FY2026  
**Currency:** ₹ Crores

## 🎯 Project Objectives

The main objectives of this project are:

- Analyse L&T's historical financial performance.
- Evaluate profitability, leverage, efficiency and cash-flow performance.
- Calculate and interpret key financial ratios.
- Identify major financial trends across FY2022–FY2026.
- Build a Discounted Cash Flow (DCF) valuation model.
- Estimate Enterprise Value, Equity Value and Intrinsic Value per Share.
- Perform WACC and Terminal Growth sensitivity analysis.
- Present financial insights using charts and a structured report.

# 📉 Sensitivity Analysis

A two-way sensitivity analysis was performed to examine the effect of changes in:

- Weighted Average Cost of Capital (WACC)
- Terminal Growth Rate

on the estimated **Intrinsic Value Per Share**.

### WACC Range

8% – 12%

### Terminal Growth Range

3% – 5%

The sensitivity table demonstrates how valuation changes under different combinations of discount rates and terminal growth assumptions.

Generally:

- Higher WACC reduces the present value of future cash flows.
- Higher terminal growth increases the estimated terminal value and intrinsic value.
